# MATLAB code

Run `setup_project.m` from the repository root before using these scripts.

Recommended order:

1. `ss_one_industry.m` (optional when using the supplied baselines)
2. `ss_two_firms_both_paths.m` (optional when using the supplied baselines)
3. `experiment.m`
4. `Crisis_Simulation.m`
5. `appendix_materials.m` after `test.m`

The `helpers/` directory contains the productivity-discretization and
steady-state objective routines called by the calibration scripts.
